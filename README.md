# L-Shape Tromino Tiling Visualizer

A Java Swing application that visualizes the Divide and Conquer algorithm for tiling a $2^n \times 2^n$ board with a single missing cell using L-shaped trominoes.

## Features
- **Algorithm:** Divide and Conquer
- **Time Complexity:** $O(N^2)$ where $N = 2^n$
- **GUI:** Java Swing visualization with unique colors for each tromino
